# Basketball sport pack — try path

Minimum happy path for a youth basketball coach (no Academy / tactics).

## Checklist

1. **Create** a club or team with sport **Basketball** (dropdown on create).
2. **Create a game** from the team (sport inherits as `basketball`).
3. **Add YouTube angles** on Game Cap / film room.
4. **Sync angles** — prefer **Audio sync**; manual sync also works.
5. **Review** — quick tags show Bucket / 3PT / Assist / Rebound / Steal / Block / Turnover / Foul (not Goal / Corner).
6. **Tag** a few plays, optionally build a short highlight reel / share room.
7. Confirm team nav has **no Tactics / Academy** tabs for basketball teams.

## Demo notes

- Coach-mark page already has basketball event buttons; align preferred sport with the game.
- Soccer teams remain unchanged when sport is soccer or unset (default soccer).
- Audio sync is sport-agnostic and recommended for multi-angle alignment.
