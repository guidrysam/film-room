# Phase A — U12 Annual Curriculum Map

**Curriculum ID (proposed):** `film-room-u12-development-v1`  
**Display name:** U12 Player Development Pathway  
**Stage:** Development  
**Age group:** U11–U12  
**Default cadence:** 2 team sessions / week (usable at 1 or 3)  
**Status:** Map revised for Phase B — player-outcome framing; no lesson payloads generated yet  
**Quality baseline:** published lesson `academy-lesson-receive-open-body`  
**Goal vocabulary:** existing `U12_ACADEMY_GOAL_CATALOG` (57 goals)

This map is a **club development framework**: a shared pathway that keeps coaches and seasons consistent. Film evidence tags may annotate lessons later; they do not drive the sequence.

---

## Product hierarchy (Phase B lock)

```text
Curriculum
  → Training Block          (capability stretch: what players should be able to do)
    → Learning Sequence     (ordered learning units inside the block)
      → Lesson Package      (atom: lesson + activities + assignment + quiz)
```

**Calendar is optional.** Clubs that train 1×, 2×, or 3× per week map learning sequences onto weeks without changing block order or package atoms.

Lesson packages remain the atom of quality. The curriculum shell sequences them; it does not replace them.

---

## Annual overview

Players should finish the year more able to **perceive → decide → execute → adapt** in 9v9-appropriate games.

Every training block answers: **What should the player be able to do after this block?**

| Metric | Count |
|--------|------:|
| Training blocks | 11 |
| Core lessons (learning-sequence slots) | 40 |
| Flexible weeks | 10 |
| Planned assessment checkpoints | 4 |
| Existing published lessons reused | 1 (`receive-open-body`) |
| Club-identity flexibility | ~10–15% of calendar |

**Cadence guidance**

- **2× / week:** follow sequences; use flexible slots as written.
- **1× / week:** keep block order; drop optional second-session reinforcement; prioritize first slots in each sequence.
- **3× / week:** add a light reinforcement session that revisits the current block’s player outcomes with a reused activity + new constraint (do not invent a third unique lesson package).

**Philosophy (coach-facing)**

- Technique only counts when it changes a game decision.
- Opposition and decisions appear early; lines and unopposed work stay brief.
- Important ideas spiral: introduce → practice → apply → master (see mastery table).
- Transition habits are woven into blocks after the first few weeks; one block emphasizes them, none owns them alone.
- Coaches may repeat a sequence when observational criteria are not met; advancing is not a schedule obligation.
- Clubs keep the pathway and use ~10–15% flexibility to express identity (possession, pressing, counter, etc.).

---

## Progression rationale

1. **Own the ball and scan** before complex combinations.  
2. **Receive open and play forward** early — already validated by the published open-body package.  
3. **Keep the ball moving** so forward play has a safe reset (support + purposeful circulation).  
4. **Beat and protect** after players can receive and shield.  
5. **Create and finish** after creation patterns exist.  
6. **Defend with purpose** after attackers understand the pictures they create.  
7. **First actions after the ball changes** — emphasis period; habits already started in earlier blocks.  
8. **Stretch and connect** as team-scale expression of earlier individual skills.  
9. **Solve pressure** integrates prior blocks at game speed.  
10. **Read and talk the game** so training transfers to matches.  
11. **Play the Game** — recognize the moment, choose, adapt, solve problems together.

## Training blocks (player outcomes)

### Block 1 — Own the Ball  
**ID:** `u12-curr-block-01-own-the-ball`  
**Core lessons:** 3 · **Default weeks:** 1–3  

| Field | Content |
|-------|---------|
| Objective | Establish safe ball security, bilateral comfort, and early scanning habits. |
| Player outcomes | Control with both feet; change surface without panic; keep the ball playable while moving. |
| Core principles | Ball stays available; eyes up between touches; retain with a purpose. |
| Prerequisites | None (entry block). |
| Transition habits | Light awareness only — notice when the ball is free; no formal win/loss protocol yet. |
| Primary goals | `u12-control-across-surfaces`, `u12-change-speed-direction`, `u12-shield-and-retain` (supporting awareness toward `u12-scan-before-receiving`; dedicated scan lesson is Block 2 L4) |
| Assessment | Can the player keep the ball available while moving and naming one nearby pressure or teammate? |
| Repeat / advance | Repeat if ball security collapses under light pressure; advance when both feet are usable in small games. |

### Block 2 — See the Next Play  
**ID:** `u12-curr-block-02-see-next-play`  
**Core lessons:** 4 · **Default weeks:** 4–7  

| Field | Content |
|-------|---------|
| Objective | Prepare an open body, direct first touch away from pressure, and keep forward options alive. |
| Player outcomes | Half-turn early; first touch solves pressure; play forward or retain with intention. |
| Core principles | Prepare before the ball arrives; see ball and next space; progress with advantage. |
| Prerequisites | Block 1 scanning and ball security. |
| Transition habits | After a lost ball in opposed work: nearest player recovers toward goal-side; after a regain: first look forward, then secure if blocked. |
| Primary goals | `u12-receive-open-body`, `u12-first-touch-away-pressure`, `u12-receive-between-lines`, `u12-scan-beyond-next-action` |
| Assessment | In a small game, does the player open before receiving and choose a useful next action? |
| Repeat / advance | Repeat closed receptions; advance when open shape appears without coach prompts. |

**Note:** Lesson #5 is the **existing published** open-body package — do not replace; reference it.

### Block 3 — Keep the Ball Moving  
**ID:** `u12-curr-block-03-keep-ball-moving`  
**Core lessons:** 4 · **Default weeks:** 8–11  

| Field | Content |
|-------|---------|
| Objective | Connect with useful weight and create angles that keep possession alive. |
| Player outcomes | Receive with purpose; support the player on the ball; pass and move; play away from pressure. |
| Core principles | Weight serves the receiver; angle before distance; secure when blocked. |
| Prerequisites | Open receiving (Block 2). |
| Transition habits | Ball lost → immediate reaction (nearest + nearest help). Ball won → first forward look, then circulate if the path is closed. |
| Primary goals | `u12-pass-weight-accuracy`, `u12-support-angle-distance`, `u12-wall-pass-combination`, `u12-choose-progress-retain` |
| Assessment | Can a pair combine under light pressure without the first passer standing still? |
| Repeat / advance | Repeat flat support; advance when support angles appear without calling. |

### Block 4 — Beat and Protect  
**ID:** `u12-curr-block-04-beat-and-protect`  
**Core lessons:** 4 · **Default weeks:** 12–15  

| Field | Content |
|-------|---------|
| Objective | Engage defenders with purpose and protect the ball after beating. |
| Player outcomes | Approach under control; exploit weight transfer; protect the exit line; choose dribble or pass. |
| Core principles | Dribble to create advantage; protect after the first step; release when cover arrives. |
| Prerequisites | Shield/retain + change of pace (Block 1); support (Block 3). |
| Transition habits | After beating a player: protect, then decide. After loss in the duel: recover goal-side immediately. |
| Primary goals | `u12-attack-defender-front-foot`, `u12-protect-after-beating`, `u12-escape-double-pressure`, `u12-choose-dribble-pass` |
| Assessment | Does the player choose dribble vs pass based on cover, not habit? |
| Repeat / advance | Repeat “move from too far”; advance when exit protection is consistent. |

### Block 5 — Create and Finish  
**ID:** `u12-curr-block-05-create-finish`  
**Core lessons:** 4 · **Default weeks:** 16–19  

| Field | Content |
|-------|---------|
| Objective | Create shooting pictures and finish under realistic pressure. |
| Player outcomes | Arrive in useful finishing zones; select surface; reload after the shot. |
| Core principles | Create before forcing; finish with the next picture in mind; celebrate the process not only the goal. |
| Prerequisites | Combinations + 1v1 (Blocks 3–4). |
| Transition habits | Shot or chance ends → immediate rest-defense shape. Regain in the final third → first action to score or cut back. |
| Primary goals | Finishing / chance-creation goals from catalog; reinforce `u12-third-player-combination`, `u12-isolate-wide-defender` |
| Assessment | In SSGs, are chances created by decision and movement—not only by gifted dribblers? |
| Repeat / advance | Repeat selfish isolation; advance when teammates create for each other. |

### Block 6 — Defend with Purpose  
**ID:** `u12-curr-block-06-defend-with-purpose`  
**Core lessons:** 4 · **Default weeks:** 20–23  

| Field | Content |
|-------|---------|
| Objective | Delay with shape, defend the ball side, and challenge at the right moment. |
| Player outcomes | Fast approach / slow arrival; protect dangerous space; recover goal-side; win and connect. |
| Core principles | Protect danger first; patience creates tackle moments; recover inside. |
| Prerequisites | Players understand attacking 1v1 pictures (Block 4). |
| Transition habits | Win the ball → first forward look. Lose the duel → recover inside the ball line. |
| Primary goals | `u12-delay-and-show`, `u12-defend-ball-side`, `u12-time-defensive-challenge`, `u12-recover-goal-side` |
| Assessment | Can a defender delay long enough for help without diving in? |
| Repeat / advance | Repeat diving tackles; advance when delays create team recovery. |

### Block 7 — First Actions After the Ball Changes  
**ID:** `u12-curr-block-07-first-actions`  
**Core lessons:** 3 · **Default weeks:** 24–26  

| Field | Content |
|-------|---------|
| Objective | Make win/loss first actions automatic under game speed (emphasis period — not the only place transition is taught). |
| Player outcomes | Urgent, purposeful first actions after turnover; balance appears behind attacks. |
| Core principles | First three seconds matter; attack with cover; defend with connection. |
| Prerequisites | Blocks 5–6; habits already practiced in Blocks 2–6. |
| Transition habits | Explicit focus: ball lost → immediate reaction; ball won → first forward look; rest defense while attacking. |
| Primary goals | Transition / rest-defense goals from catalog; `u12-balance-behind-ball` |
| Assessment | After a regain, does the nearest player secure or progress without freezing? |
| Repeat / advance | Repeat ball-watching after loss; advance when first actions are automatic. |

### Block 8 — Stretch and Connect  
**ID:** `u12-curr-block-08-stretch-connect`  
**Core lessons:** 4 · **Default weeks:** 27–30  

| Field | Content |
|-------|---------|
| Objective | Stretch the field and combine to play through or around. |
| Player outcomes | Hold useful width; provide connected depth; find third-player solutions; switch when crowded. |
| Core principles | Make the field big; depth must stay connected; combine when numbers exist. |
| Prerequisites | Support (Block 3) + progress/retain decisions. |
| Transition habits | Switch or loss of the far side → immediate compactness; regain on the weak side → first forward look. |
| Primary goals | `u12-use-full-team-width`, `u12-provide-penetrating-depth`, `u12-third-player-combination`, `u12-switch-point-attack` |
| Assessment | Does width open a central lane that teammates actually use? |
| Repeat / advance | Repeat disconnected width; advance when far-side players reconnect. |

### Block 9 — Solve the Press  
**ID:** `u12-curr-block-09-solve-press`  
**Core lessons:** 3 · **Default weeks:** 31–33  

| Field | Content |
|-------|---------|
| Objective | Solve compact pressure with scanning, open receiving, and secure circulation. |
| Player outcomes | Recognize traps; escape or combine early; switch when crowded. |
| Core principles | See the second defender; circulate before forcing; progress when advantage appears. |
| Prerequisites | Blocks 2, 3, 7, 8. |
| Transition habits | Forced turnover under press → counter-press or recover shape together (no freeze). |
| Primary goals | `u12-escape-double-pressure`, `u12-receive-between-lines`, `u12-recognize-overload-isolation`, `u12-switch-point-attack` |
| Assessment | Under a high press in training, can the team find a free player without panic clearances? |
| Repeat / advance | Repeat forced long balls; advance when secure first passes appear. |

### Block 10 — Read and Talk the Game  
**ID:** `u12-curr-block-10-read-talk`  
**Core lessons:** 3 · **Default weeks:** 34–36  

| Field | Content |
|-------|---------|
| Objective | Name pictures, communicate useful information, and transfer training to matches. |
| Player outcomes | Give simple information; reflect on decisions; link match moments to training goals. |
| Core principles | Language is short and useful; reflection is specific; confidence includes creativity. |
| Prerequisites | Most prior blocks introduced. |
| Transition habits | Language cues for win/loss (“ball!” / “time!” / “cover!”) become automatic. |
| Primary goals | Leadership / communication / reflection goals from Block 6 of the goal catalog |
| Assessment | Can a player explain one successful and one failed decision from a recent game without blaming teammates? |
| Repeat / advance | Repeat vague language; advance when cues are actionable. |

### Block 11 — Play the Game  
**ID:** `u12-curr-block-11-play-the-game`  
**Core lessons:** 4 · **Default weeks:** 37–40  

| Field | Content |
|-------|---------|
| Objective | Bring the year together: recognize the moment, choose the right action, adapt, and solve problems. |
| Player outcomes | Recognize the moment; choose the right action; adapt when the picture changes; solve problems with teammates. |
| Core principles | Assessment informs coaching, not talent labels; reinforce before inventing new content; games over topics. |
| Prerequisites | Blocks 1–10. |
| Transition habits | Full-game win/loss habits under match-like constraints. |
| Primary goals | Coach-selected from earlier blocks based on observation |
| Assessment | Pathway checklist (below); decide advance / reinforce / simplify / assign individual work. |
| Repeat / advance | Stay in this block until the checklist is honest; do not invent Block 12 content. |

This is **not** a passing / defending / finishing silo. It is integrated game competence.

## Flexible weeks (10) — club identity room

These are **slots**, not unique doctrine lessons. Together with club-priority flex, they are the main **~10–15% identity lever**: a possession club, pressing club, or counterattacking club keeps the same pathway while emphasizing different ideas in flex and within-session constraints.

| ID | Name | Typical use | Suggested placement |
|----|------|-------------|---------------------|
| `u12-flex-01-opening-baseline` | Opening baseline observation | Watch habits; light games; no new concepts | Before or during Block 1 |
| `u12-flex-02-reinforce-receive` | Reinforce receiving / scanning | Repeat activities from lessons 4–6 with new constraints | After Block 2 |
| `u12-flex-03-weather-catchup` | Weather / catch-up | Resume incomplete lesson; indoor adaptations | Anywhere |
| `u12-flex-04-tournament-prep-a` | Tournament prep A | Simplify; rest-defense + first actions; confidence | Before major event |
| `u12-flex-05-midyear-assessment` | Mid-year observational assessment | Checklist half-year; decide reinforce vs advance | After Block 5 or 6 |
| `u12-flex-06-club-priority` | Club identity week | Possession / pressing / counter emphasis without leaving the pathway | Mid season |
| `u12-flex-07-tournament-prep-b` | Tournament prep B | Same as A with opponent notes only if observed | Late season |
| `u12-flex-08-weather-catchup` | Weather / catch-up | Second buffer | Anywhere |
| `u12-flex-09-endyear-reinforce` | End-year reinforcement | Coach picks weakest spiral (receive / support / defend) | Before Block 11 |
| `u12-flex-10-final-assessment` | Final pathway assessment | Full observational checklist; individual assignments | After lesson 40 or replacing 40 if needed |

**Club identity guidance**

- Keep core lesson order and spiral coverage.
- Use flex weeks + activity constraints (not new doctrine packages) for identity.
- Target **10–15%** of annual calendar as flexible / identity emphasis.
- Film Room publishes the pathway; clubs fork with `ownership.kind: "club"` and pin a version per season.

**Total calendar capacity:** 40 core + 10 flexible ≈ one club year without inventing 52 unique lessons.

## Assessment checkpoints

Observational only — no talent or medical claims.

| Checkpoint | When | Coach decides |
|------------|------|---------------|
| Opening baseline | Flex 01 | Starting emphasis for Block 1–2 |
| End of Block 2 | After L7 | Repeat receive/scan or continue |
| Mid-year | Flex 05 | Reinforce vs advance into defending / first-actions emphasis |
| Final pathway | Flex 10 / L40 | Individual assignments; next-season priorities |

**Sample observable checklist (player-level)**

- Scans before receiving  
- Receives across / open when pressure allows  
- Recognizes pressure side  
- Supports at a useful angle  
- Attempts forward play when appropriate  
- Protects the ball  
- Reacts after possession changes (woven + emphasis)  
- Communicates something useful  
- Recognizes the moment and chooses under game speed  

Scores, if used at all, are **coaching notes**, not rankings.

## Shared activity strategy (generation guidance)

Do **not** create one unique activity per lesson.

Reuse families with new constraints:

| Family | Appears across | Variation method |
|--------|----------------|------------------|
| Gate / channel receiving | L4–L6, L33 | Cue timing, pressure side, exits |
| Diamond / directional receiving | L5–L7, L33 | Add bounce, third player, press |
| Support rondo / possession | L8–L11, L32 | Touch limits, directional targets |
| 1v1 corridors | L12–L16, L20–L22 | Attack then defend same picture |
| End-zone / multi-goal SSG | Most blocks | Scoring rules encode the weekly objective |
| Transition bounce games | Woven Blocks 2–6; emphasis L24–L26 | Instant switch of roles |

Open-body activities (`academy-warmup-open-body-gates`, `academy-activity-open-body-diamond`, `academy-ssg-open-body-end-zones`) are the **template for quality** and remain the activity set for L5.

## Sample learning-session structure (every core lesson package)

1. Arrival / dynamic ball warmup (canonical activity)  
2. Technical or opposed learning activity  
3. Decision-rich progression  
4. Small-sided game (include win/loss first-action cues after Block 1)  
5. Brief reflection  

**Duration:** 75 min default; 60 min short variant (merge progression into SSG); 90 min long variant (extra opposed rep).

Each lesson later carries: assignment, 4–6 question quiz, optional tactics preset, evidence tags only when useful.
